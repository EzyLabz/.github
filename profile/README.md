# Welcome to EzyLabs

![EzyLabs banner](./ezylabs-banner.png)

We build Python tools and bots for the Yapper community.

## EzyTools

Build Yapper bots with reusable Python helpers for command arguments, permissions, moderation, server settings, and message formatting.

```bash
python -m pip install ezytools
```

[Repository](https://github.com/EzyLabz/ezytools) · [Wiki](https://github.com/EzyLabz/ezytools/wiki) · [Releases](https://github.com/EzyLabz/ezytools/releases) · [PyPI](https://pypi.org/project/ezytools/)
